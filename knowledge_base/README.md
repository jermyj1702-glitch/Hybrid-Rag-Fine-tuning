# Knowledge Base

This directory contains the 13 SOP and corporate policy documents used
as the knowledge base for the Retrieval-Augmented Generation (RAG)
pipeline.

These documents provide the policy context used during semantic retrieval
and response generation.

## Documents

- Account Recovery
- Billing Disputes
- Data Privacy
- Escalation Matrix
- Order Tracking
- Password Reset
- Payment Methods
- Product Return
- Refund Policy
- Shipping Delays
- Subscription Cancellation
- Technical Troubleshooting
- Working Hours

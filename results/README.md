# Results

This directory contains the evaluation results and training outputs
generated during the project.

## Evaluation

The project compares:

- Baseline (Zero-Shot)
- Naive RAG
- Hybrid RAG

Key evaluation metrics include:

- ROUGE-1
- ROUGE-L
- BLEU
- Hallucination Rate
- Retrieval Precision

See `Comparative_Results_Summary.csv` for the consolidated results.
